# Versa Core (`versa_core`)

Core platform application for Versa ERP providing:
- Dynamic Multi-Level Financial Approval Rules (`Versa Approval Rule`)
- Multi-Company Query Conditions & Tenant Isolation (`multi_company_isolation`)
- Credit Limit & Overdue Invoice Commercial Policy Engine
- Supplier OTIF (On-Time In-Full) Performance Analytics
- ERPNext Standard Document Governance Hooks
